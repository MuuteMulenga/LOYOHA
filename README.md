## 🚀 Deploying to GitHub Pages

### Step 1: Create a GitHub Repository
1. Go to [github.com](https://github.com) and create a new repository
2. Name it something like `loyoha-website` or `loyoha-investments`
3. Make it **Public** (required for free GitHub Pages)
4. Don't initialize with README, .gitignore, or license (we already have those)

### Step 2: Push Your Code
After creating the repository, run these commands in your terminal:

```bash
# Add all files to git
git add .

# Commit your changes
git commit -m "Initial commit - LOYOHA Investments website"

# Add your GitHub repository (replace with your actual URL)
git remote add origin https://github.com/YOUR_USERNAME/loyoha-website.git

# Push to GitHub
git branch -M main
git push -u origin main
```

### Step 3: Enable GitHub Pages
1. Go to your repository on GitHub
2. Click **Settings** tab
3. Click **Pages** in the left sidebar
4. Under **Source**, select **Deploy from a branch**
5. Select **main** branch and **/ (root)** folder
6. Click **Save**

### Step 4: Access Your Site
Your site will be live at:
```
https://YOUR_USERNAME.github.io/loyoha-website/
```
